# 公開用整理の変更点

## 2026-10-10（v1.0.1）

文書、確認スクリプト、テストの追加、Notebookの表示の訂正だけです。`code/model.py`・`code/scenarios.json`・`results/`・`images/` は変更していません。計算式・仮定・保存結果・図は v1.0.0 と同じです。既定ブランチは `main` になりました。

- 古い記述を直しました。README・CHANGELOG・確認記録にあった「GitHubには公開していない」という趣旨の文を、公開済みの事実に合わせました。READMEの題は、公開した記事の題に合わせました。
- 確認スクリプト `verify_reproduction.py`：保存結果との比較を、全文の一致から値の比較に変えました。JSONは構造を読み、数値は相対誤差 1e-9 以内なら一致、文字列は完全一致です。CSVはセルごとに同じ基準で比べます。Python 3.11 では最終桁の差で「保存結果と違う」と落ちていましたが、3.10・3.11・3.12・3.14 で通ります。
- READMEの実行手順：確認だけの手順（保存結果を書き換えない）を先に置き、保存結果を上書きする手順に注意書きを付けました。確認したPythonの版（3.10・3.11・3.12・3.14）を書きました。
- `code/requirements-plots.txt`：図の再生成を確認した版（numpy 1.26.4・matplotlib 3.8.0）に固定しました。Python 3.13 以降には入らないため、版の条件を付けています。
- Notebook：億円の表示を小数第4位までにしました（表示だけで、値は同じです）。小数第3位の表示を記事の小数第2位へもう一度丸めると、自然移行30%の値（保存値 8.8648億円）が 8.87 になります。小数第4位から一度だけ丸めると 8.86 です。保存した出力は再実行して入れ替えました。
- テスト：記事に出るモデル由来の数字を表にして、保存結果を一度だけ丸めた値と照合するテストを足しました（テストは29本）。確認スクリプトは、`results/` のファイル一覧が比較対象と違うときにも失敗します。
- 利用条件：`RIGHTS.md` を、作者の公開リポジトリ共通の文面に差し替えました。READMEの該当行も言い換えました。
- `.gitignore`：使っていない行（作業用フォルダ名）を消しました。
- 各ファイルの SHA-256 一覧（`MANIFEST.json`）を更新しました。
