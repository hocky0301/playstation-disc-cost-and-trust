# モデルの範囲と結果の読み方

## 何を計算しているか

ディスク供給からデジタル供給へ移行する仮想施策について、移行しない未来との差を計算します。
入力はすべて説明用の仮定です。ソニーの内部原価・顧客データ・実際の離脱率は使っていません。
このコードは実際の政策発表の存在や妥当性を検証するものではありません。
記事の外部事実に関する出典確認と、ここでの計算の確認は別の作業です。

## 簡略モデル

```text
利益現在価値の差 = N * ((1-d) * (1-e) * (L+G) - L) + F - K
```

- N：分析対象の人数。
- L：施策をしない場合の一人あたり将来貢献利益の現在価値。
- G：残る一人あたりの移行による追加貢献利益。同じ費用削減をFへ重複計上しない。
- d：施策による追加離脱率。自然な離脱率ではない。
- e：残る人の貢献利益の減少率。LとGの両方に作用する。
- F：実際に回避できる固定費の現在価値。
- K：移行費用の現在価値。

金額はすべて同じ対象・期間・基準時点へ揃えます。売上と貢献利益を混ぜないでください。
実装上、費用・利益入力は非負、比率は0〜1です。マイナスの移行増益を直接指定する用途には、そのまま適用できません。

## 五年モデル

`code/scenarios.json` が入力です。共通条件、仮想顧客群、施策ごとの反応と費用を定義します。
自然なデジタル移行は、施策をしなかった基準案にも発生します。
追加離脱・年次追加離脱・買い控え・継続支援費を分けています。

開始時点の顧客群だけを追跡するモデルです。新規獲得、期末残存価値、株価、企業価値、
次世代機販売、友人や開発者への波及は計算しません。
仮想顧客群の人数を実市場の比率として扱わないでください。

## 結果ファイル

- `results/results.json`：基礎計算、各施策の五年NPV、年次分解、完全情報価値の数値例。
- `results/policies.csv`：施策別のNPVと各要素の現在価値。
- `results/yearly.csv`：各年の差額。初期移行費は年次線の外で控除します。
- `results/sensitivity.json`：支援が顧客反応を変えないケースなど。
- `results/natural_migration.csv`：自然移行率0%、15%、30%の比較。
- `results/simple_frontier.csv`：追加利益と追加離脱の9,211組。実験サンプル数ではありません。

完全情報の価値は、入力した状態と重みに基づく上限です。実際の調査効果や成功確率の推定ではありません。
テストが通ることは計算の整合性の検査であり、仮定が現実を表していることの証明ではありません。

## 変更した場合

入力、期間、単位、対象、比較する未来、出典を記録してください。
`scenarios.json` を変えたら計算と感度分析を更新し、その後で図を再生成します。
記事の数値を更新するときは、その計算に使ったコミットを併記することを推奨します。
